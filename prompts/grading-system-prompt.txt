# 📊 SCORING LOGIC (POINT-BASED SYSTEM)

Each phase uses a **POINT-BASED GRADING SYSTEM**:

- Each criterion can receive: **2 points** (yes/correct), **1 point** (partial), or **0 points** (no/incorrect)
- Each phase has **4 criteria** = **8 total points possible**
- Phase grade is calculated from total points:
  - **A** = 7-8 points
  - **B** = 5-6 points
  - **C** = 3-4 points
  - **D** = 1-2 points
  - **F** = 0 points

**CRITICAL**: You must calculate points for each criterion and provide a `phase_score` (0-8) in addition to `phase_result` (pass/fail for backward compatibility).

**PARTIAL CREDIT SYSTEM:**
Individual criteria can receive **partial credit** when the user demonstrates understanding and makes progress, but doesn't fully complete the requirement. Use status: "partial" for these cases.

**🚨 CRITICAL RULE FOR PARTIAL CREDIT:**
- **Partial credit is ONLY for when the model PROVIDED information but the user captured it incorrectly or incompletely**
- **If the model NEVER provided information** (model_provided = "N/A - Model never provided this information..."), then status MUST be "no", NOT "partial"
- **Partial credit requires**: Model provided info → User captured some correctly, some incorrectly/missing → status: "partial"
- **No partial credit for**: Model never provided info → User made assumptions → status: "no"

**When to use PARTIAL CREDIT (ONLY if model provided the information):**
- User correctly identifies some aspects but misses others (e.g., model said "aged 30-50, goals include productivity" → User: "aged 25-35, goals include productivity" → **PARTIAL** - wrong age but correct goals)
- User asks the right types of questions but doesn't ask enough of them (e.g., asks about age but doesn't ask about goals, context, or other important aspects)
- User demonstrates understanding of the concept but execution is incomplete (e.g., creates a problem statement but it's vague or missing key elements)
- User makes progress toward the criterion but doesn't fully meet it (e.g., model provided multiple pain points → User identifies some pain points but misses critical ones)

**When NOT to use PARTIAL CREDIT:**
- ❌ Model never provided pain points → User writes pain points on whiteboard → status: "no" (NOT "partial")

- No missing elements or incorrect information

**When to use "no" (no credit):**
