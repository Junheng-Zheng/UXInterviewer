<whiteboard_grading_philosophy>
## KEY PRINCIPLE: "If it's not in the diagram, it didn't happen."

This is a **speed whiteboarding session** where thinking under pressure is the skill being tested.

**What "Good" Looks Like:**
✅ Rough boxes and lines (not pixel-perfect)
✅ Messy with crossed-out sections (shows iteration)
✅ Lots of text annotations (shows reasoning)
✅ Multiple sketches or options explored
✅ "Why" is visible, not just "what"
✅ User needs explicitly called out
✅ Trade-offs and questions documented

**What "Bad" Looks Like:**
❌ Too polished/clean (spent time on wrong thing)
❌ No annotations or reasoning
❌ Single solution with no alternatives
❌ No user context or problem framing
❌ Features without justification
❌ Missing edge cases or states
❌ No prioritization or scope awareness

**Judge by THINKING not POLISH:**
- Messy but thoughtful > Clean but shallow
- Rough sketch with reasoning > Pretty mockup without context
- Multiple rough ideas > One polished solution
- Annotated process > Silent artifact

Remember: Candidates had 15-30 minutes under pressure. Grade their design thinking process as evidenced in the artifact, not their visual design skills.
</whiteboard_grading_philosophy>

<excalidraw_grading_rubric>
When evaluating an Excalidraw diagram submitted during a whiteboarding exercise:

1. **Identify all elements**: UI components, labels, connections, annotations, crossed-out ideas, notes, sketches.
2. **Look for evidence of thinking**: Multiple approaches, iterations, reasoning notes, user context, trade-offs.
3. **Grade based on THREE dimensions** (total 100 points):

## DIMENSION 1: THINKING & PROBLEM-SOLVING (50 points)

### 1.1 Problem Definition (12 points)
**What to look for:**
- Problem restated in candidate's own words (written on board)
- 2+ user types identified
- Key constraints/assumptions noted
- Clear "success = ..." statement

**Scoring:**
- **10-12 points**: Problem summary visible, 2+ user types, constraints noted, success defined
- **7-9 points**: Problem mentioned, user type(s) identified, some constraints
- **3-6 points**: Vague problem reference, generic "users", no constraints
- **0-2 points**: No problem context, jumped straight to UI

**Objective indicators:**
✅ Text box with problem summary
✅ "Users: [specific type]" noted
✅ "Constraints: [X]" or "Assumptions: [Y]" visible
⚠️ Messy handwriting OK - content matters, not beauty

### 1.2 Evidence of Exploration (15 points)
**What to look for:**
- 2-3 approaches sketched (even rough)
- Crossed-out ideas visible
- "Option A vs B" or similar comparison
- Notes on why they chose their direction
- Shows what they're NOT solving

**Scoring:**
- **13-15 points**: 2-3 approaches visible, crossed-out elements, comparison notes, rationale for direction
- **9-12 points**: 2 approaches visible, some crossed-out elements, basic comparison
- **5-8 points**: 1 approach with minor variations, minimal iteration, vague rationale
- **0-4 points**: Single idea only, too clean (no iteration), no alternatives

**Objective indicators:**
✅ Multiple sketches/sections exploring options
✅ Visible erasures, strikethroughs, "X" marks
✅ Labels like "Option 1", "Alt approach", "Considered but..."
✅ Rough/messy is GOOD - shows real-time thinking
⚠️ Perfectly clean diagram = RED FLAG (didn't iterate)

### 1.3 User-Centered Rationale (12 points)
**What to look for:**
- Features explicitly tied to user needs (annotations)
- User pain points called out (3+)
- User journey or scenario sketched
- Notes about different user types
- "This solves [specific pain]" visible

**Scoring:**
- **10-12 points**: Features tied to needs, 3+ pain points, user journey sketched, different personas noted
- **7-9 points**: Some user need references (2), 1-2 pain points, basic user mention
- **3-6 points**: Vague user references, features not connected to needs, generic pain points
- **0-2 points**: No user references, feature-focused only

**Objective indicators:**
✅ Annotations like "Users need X because..."
✅ Pain points written out
✅ User flow or journey sketched
✅ Different personas/segments noted
⚠️ If features exist without "why" → major deduction

### 1.4 Critical Thinking & Trade-offs (11 points)
**What to look for:**
- Trade-offs documented (pros/cons, +/- notes)
- Open questions called out ("Need to validate...")
- Limitations acknowledged
- "If more time, would..." notes
- Alternative approaches mentioned with reasoning

**Scoring:**
- **9-11 points**: Trade-offs documented, open questions, limitations noted, future considerations, humble language
- **6-8 points**: Some trade-offs mentioned, 1-2 questions noted, basic limitations
- **2-5 points**: Minimal critical thinking, no trade-offs, presents solution as perfect
- **0-1 points**: No critical analysis, no questioning or reflection

**Objective indicators:**
✅ "Pros/Cons" lists
✅ "?" marks or "Uncertain about..."
✅ "Trade-off: X vs Y" notes
✅ "Assumptions to validate:" section
✅ Humble language, not overconfident

## DIMENSION 2: SOLUTION LOGIC & STRUCTURE (35 points)

### 2.1 Solution Completeness (12 points)
**What to look for:**
- Addresses all 3 parts of brief (Design/For/To Help)
- Shows 3+ key screens/states (rough boxes OK)
- Includes edge cases (error, empty, loading)
- Shows full journey (start → goal)
- Prioritization visible (MVP notes)

**Scoring:**
- **10-12 points**: Addresses full brief, 3+ screens, edge cases, complete journey, MVP prioritization
- **7-9 points**: Addresses main requirements, 2-3 screens, 1 edge case, most of journey
- **3-6 points**: Partially addresses brief, 1-2 screens, happy path only, gaps in journey
- **0-2 points**: Misses brief, incomplete, no clear solution

**Objective indicators:**
✅ Minimum 3 screens/states (simple boxes fine)
✅ Error/empty state shown (even if noted as "TODO")
✅ Flow from entry to goal visible
✅ "MVP" or "P1/P2" priority labels
⚠️ Boxes with text > fancy mockups with no context

### 2.2 Flow & Interaction Logic (10 points)
**What to look for:**
- Clear arrows showing flow
- All actions have destinations
- Back navigation shown
- Decision points have paths
- No dead ends

**Scoring:**
- **9-10 points**: Clear flows, all actions connected, navigation shown, decision paths clear, no dead ends
- **6-8 points**: Most flows clear, most actions connected, basic navigation, 1-2 minor gaps
- **3-5 points**: Some unclear flows, missing connections, navigation issues
- **0-2 points**: Broken or missing flows, no clear logic

**Objective indicators:**
✅ Arrows connect elements (straight lines OK)
✅ Every button/action points somewhere
✅ Back buttons or navigation noted
✅ "If X then Y" conditional logic shown
⚠️ Messy arrows OK if labeled

### 2.3 Information Architecture (8 points)
**What to look for:**
- Clear hierarchy (size/position)
- Related items grouped
- Logical flow (top-down or left-right)
- Primary actions emphasized

**Scoring:**
- **7-8 points**: Clear hierarchy, good grouping, logical flow, primary actions emphasized
- **5-6 points**: Basic hierarchy, some grouping, flow makes sense
- **2-4 points**: Flat structure, random placement, unclear flow
- **0-1 points**: No structure, chaotic

**Objective indicators:**
✅ Important things larger/higher
✅ Related items near each other
✅ Can trace a logical path
⚠️ Rough layout OK if structure is clear

### 2.4 Technical Feasibility (5 points)
**What to look for:**
- Realistic for timeframe
- MVP vs future noted
- Scoping visible
- Tech constraints acknowledged

**Scoring:**
- **5 points**: Realistic scope, MVP vs future noted, reasonable features, constraints acknowledged
- **3-4 points**: Mostly realistic, some prioritization
- **1-2 points**: Overly ambitious, no prioritization
- **0 points**: Completely unrealistic

**Objective indicators:**
✅ "MVP: [core features]" labeled
✅ "Phase 2: [future]" noted
✅ Reasonable scope (not 50 features)
✅ Comments about constraints

---

## DIMENSION 3: COMMUNICATION ON DIAGRAM (15 points)

### 3.1 Clarity & Labels (8 points)
**What to look for:**
- 80%+ of elements labeled
- Key actions described
- Readable (even if messy)
- Consistent-ish notation

**Scoring:**
- **7-8 points**: 80%+ labeled, key actions described, readable, consistent notation
- **5-6 points**: 60%+ labeled, mostly readable, some consistency
- **2-4 points**: 40%+ labeled, hard to read, no consistency
- **0-1 points**: Mostly unlabeled, illegible

**Objective indicators:**
✅ Text on most boxes
✅ Arrow labels (action names)
✅ Readable from screenshot
⚠️ Handwriting quality doesn't matter if readable

### 3.2 Annotations & Narration (7 points)
**What to look for:**
- Rich annotations explaining "why"
- Numbers showing sequence (1, 2, 3...)
- Callout notes/arrows
- Thinking process visible in notes

**Scoring:**
- **6-7 points**: Rich annotations, numbered sequence, callout notes, thinking process visible
- **4-5 points**: Some annotations, basic sequencing, a few notes
- **1-3 points**: Minimal annotations, just shapes with little context
- **0 points**: No annotations

**Objective indicators:**
✅ Notes like "Because...", "This helps..."
✅ Numbers showing order/steps
✅ Callout boxes explaining decisions
✅ Sticky notes or side comments
⚠️ More text = better (shows thinking)

<scoring_interpretation>
## SCORING GUIDE FOR WHITEBOARD CONTEXT

| Grade | Score | Description |
|-------|-------|-------------|
| **Exceptional** | 90-100 | Strong thinker. Clear process, multiple options, user-focused, well-reasoned. Messy is fine. |
| **Strong** | 75-89 | Good thinking. Shows alternatives, user awareness, solid logic. Minor gaps OK. |
| **Good** | 60-74 | Acceptable. Shows some thinking but missing depth. Surface-level reasoning. |
| **Fair** | 45-59 | Weak process. Limited exploration, unclear reasoning, gaps in logic. |
| **Weak** | 0-44 | Poor thinking. No alternatives, no user focus, illogical, or incomplete. |

## RED FLAGS (Automatic -10 points each, max -20 total)
❌ Diagram too polished (spent time on visuals not thinking)
❌ No problem definition or user context
❌ No annotations or reasoning visible
❌ Single solution with no alternatives explored
❌ Completely misses the brief

## BONUS POINTS (Up to +5 points total)
✅ Exceptional depth of reasoning (+3)
✅ Explored 3+ distinct approaches (+2)
✅ Explicitly validated assumptions or showed testing plans (+2)
✅ Acknowledged uncertainty/unknowns (+1)

## EVALUATION CHECKLIST

Before scoring, ask:
1. ☐ Can I see what problem they understood?
2. ☐ Can I see evidence they explored options?
3. ☐ Can I see why they made key decisions?
4. ☐ Can I see user needs addressed?
5. ☐ Can I see trade-offs they considered?
6. ☐ Can I trace the flow/logic?
7. ☐ Can I see what they'd do with more time?

**Key Question:** "Can I follow their thought process from this diagram alone?"
- If yes → Good score
- If no → Deductions for lack of visible reasoning

If 5+ checked → Likely 70+ score
If 3-4 checked → Likely 50-70 score
If 0-2 checked → Likely <50 score
</scoring_interpretation>
